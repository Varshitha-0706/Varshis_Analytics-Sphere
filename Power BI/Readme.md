# 🎬 Netflix Power BI Dashboard

An interactive **Power BI Dashboard** built to analyze Netflix Movies and TV Shows using data visualization techniques. The dashboard provides valuable insights into Netflix's content library, including genre distribution, ratings, release trends, popular titles, and audience engagement.

---

## 📌 Project Overview

This project focuses on exploring Netflix's catalog through interactive dashboards in **Microsoft Power BI**. Data from two Kaggle datasets was combined to provide comprehensive insights into content availability, popularity, and viewer preferences.

The dashboard enables users to:

* Analyze Movies vs TV Shows
* Explore content by Genre
* View IMDb Ratings and Votes
* Identify Top Rated Titles
* Analyze Release Year Trends
* Explore Content Ratings (TV-MA, PG-13, etc.)
* Filter data dynamically using slicers

## 📂 Datasets Used

### 1. Netflix Popular Movies Dataset (IMDb)

Contains detailed information about Netflix movies and TV shows including IMDb ratings, votes, certificates, genres, cast, and descriptions. ([Kaggle][1])

**Dataset Link**

[https://www.kaggle.com/datasets/narayan63/netflix-popular-movies-dataset](https://www.kaggle.com/datasets/narayan63/netflix-popular-movies-dataset)

---

### 2. Netflix Movies and TV Shows Dataset

Contains metadata such as title, type, director, country, release year, date added, duration, ratings, genres, and descriptions. It is widely used for Netflix content analysis projects. ([Zenodo][2])

**Dataset Link**

[https://www.kaggle.com/datasets/shivamb/netflix-shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
